Инструкция по работе с приложением «Приборы КИП»

Руководство пользователя: учёт приборов, документы, журнал операций и управление доступом.

Содержание 1. Назначение и начало работы 2. Пользователи и доступ 3. Все приборы 4. На позиции 5. Склад 6. КИП 7. Документы 8. Перемещения 9. Журнал 10. Позиции 11. Корзина 12. Печать и экспорт 13. Рекомендации

1. Назначение и начало работы

Приложение «Приборы КИП» предназначено для учёта приборов, хранения их характеристик, контроля сроков поверки и сопровождения основных операций: установки на позицию, перемещения на склад, передачи в КИП, возврата и списания.

Для перехода к нужному разделу используйте верхнее меню. Рабочие вкладки «На позиции», «Склад» и «КИП» показывают приборы в соответствующем состоянии. Прибор не копируется между разделами — меняется его состояние, а история операции записывается в систему.

2. Пользователи и доступ

В верхней части страницы можно выбрать пользователя. Для входа под сотрудником выберите его имя и введите пароль. Гостевой режим предназначен для просмотра.

  • Гость — просмотр данных без возможности изменять их.
  • Пользователь — выполнение рабочих операций с приборами и документами.
  • Администратор — рабочие операции и управление учётными записями.

Для завершения работы нажмите «Выйти». Не передавайте свой пароль другим сотрудникам.

3. Все приборы

Вкладка «Все приборы» содержит общий справочник приборов. Здесь можно найти запись, посмотреть или изменить характеристики, добавить прибор либо отправить запись в корзину.

Поиск и фильтры

  • Используйте строку поиска для поиска по названию, заводскому номеру или позиции.
  • Фильтры под заголовками столбцов позволяют уточнять список по отдельным полям. Несколько фильтров действуют одновременно.
  • В столбцах с датами могут быть доступны варианты сортировки. Нажмите «Сбросить фильтры», чтобы очистить фильтрацию и вернуться к исходному отображению.

Добавление и редактирование

  1. Для создания записи нажмите «+ Добавить прибор».
  2. Заполните доступные поля. Заводской номер и позиция должны быть указаны в принятом на предприятии формате.
  3. При необходимости добавьте фото и заполните технические характеристики.
  4. Нажмите «Сохранить». Для редактирования откройте карточку прибора и выберите соответствующее действие.

Статус поверки отображается по дате следующей поверки. Сверяйте исходные даты: автоматический статус не заменяет проверку документации прибора.

4. На позиции

Вкладка «На позиции» показывает приборы, которые установлены или закреплены за рабочими позициями.

  1. Найдите нужные приборы с помощью строки поиска и фильтров.
  2. Отметьте чекбоксами один или несколько приборов. Счётчик рядом с кнопками показывает количество выбранных.
  3. Нажмите «Переместить на склад» и дождитесь завершения операции.
  4. Чтобы отменить выбор до операции, нажмите «Снять выделение».

После перемещения приборы меняют рабочий раздел и отображаются на вкладке «Склад».

5. Склад

На вкладке «Склад» отображаются приборы, находящиеся на хранении. Таблица содержит основные характеристики, включая тип датчика и дату поступления на склад.

Передача в КИП

  1. Найдите приборы, которые необходимо передать, используя поиск и фильтры.
  2. Отметьте нужные строки чекбоксами. При необходимости можно выбрать несколько приборов.
  3. Нажмите «Передать в КИП».
  4. После завершения передачи выбранные приборы перейдут во вкладку «КИП», а выделение в текущем списке будет очищено.

Списание

Выберите приборы и нажмите «Списать», если они выводятся из учёта. Списанные приборы не следует передавать на позицию или возвращать в обычный рабочий оборот.

Кнопка «Снять выделение» отменяет выбор строк без изменения данных приборов. Подсветка строк не означает, что прибор выбран для операции — ориентируйтесь на чекбоксы и счётчик «Выбрано».

6. КИП

Раздел «КИП» содержит приборы, переданные для поверки, ремонта или другой работы в КИП.

  • Вернуть на склад — возвращает выбранные приборы из КИП на склад.
  • Установить на позицию — переводит выбранные приборы в состояние установки. Перед установкой проверьте правильность позиции и данные прибора.
  • Списать — переводит приборы в состояние списания.

Для выполнения действия отметьте нужные приборы и нажмите соответствующую кнопку. Для отмены выбора используйте «Снять выделение». Проверяйте счётчик выбранных приборов перед выполнением массовой операции.

7. Документы

Раздел позволяет создавать документы и включать в них перечни приборов. Добавление прибора в документ не создаёт новую запись в базе и не меняет его положение.

  1. Нажмите «+ Создать документ» и заполните название. Номер и описание можно указать дополнительно.
  2. Откройте созданный документ из списка.
  3. Нажмите «Добавить прибор», найдите прибор по названию, заводскому номеру или позиции, выберите его и подтвердите добавление.
  4. Чтобы исключить прибор из документа, используйте действие удаления в строке прибора внутри документа.

Удаление документа не удаляет сами приборы из справочника.

8. Перемещения

Вкладка «Перемещения» предназначена для просмотра истории зарегистрированных операций с приборами.

  • Поиск позволяет отфильтровать записи по прибору, заводскому номеру, операции, месту или примечанию.
  • «Последние 150» показывает ограниченный список последних операций.
  • «Загрузить все» запрашивает полный доступный журнал перемещений.

Записи истории помогают проследить, когда, куда и кем был перемещён прибор.

9. Журнал

Журнал действий фиксирует операции пользователей: создание, редактирование, перемещение, удаление и восстановление приборов, а также действия с документами и учётными записями, если они предусмотрены.

Используйте «Обновить» для загрузки последних записей, «Показать все» — для просмотра полного доступного журнала. Кнопка экспорта позволяет сохранить журнал в CSV.

10. Позиции

Справочник «Позиции» содержит список позиций и связанные с ними наименования и оборудование.

  • Введите текст в поле поиска для поиска по позиции, наименованию или оборудованию.
  • Нажмите «Обновить», чтобы загрузить актуальные данные.
  • Используйте действия в строке для редактирования или удаления записи, если это доступно вашей роли.

При заполнении карточек приборов используйте единообразные обозначения позиций из справочника.

11. Корзина

При удалении прибора из основного списка запись перемещается в корзину. Удаление из основного списка не следует путать со списанием прибора.

  1. Откройте вкладку «Корзина».
  2. Нажмите «Обновить», если требуется актуализировать список.
  3. Найдите прибор и нажмите «Восстановить».
  4. После восстановления прибор снова появится в общем списке.

12. Печать и экспорт

  • Экспорт списка приборов в CSV доступен из раздела «Все приборы».
  • Экспорт журнала действий доступен в разделе «Журнал».
  • Печать карточки прибора доступна из его карточки.
  • Кнопка «Печать инструкции» печатает эту страницу. В диалоге браузера можно выбрать принтер или сохранить документ в PDF.

13. Рекомендации

  • Перед массовым перемещением проверьте выбранные приборы и счётчик количества.
  • Выделение чекбоксом — это выбор для операции. Цвет строки может обозначать другое состояние и сам по себе не означает выбора.
  • Не создавайте дубликаты приборов: перед добавлением используйте поиск по заводскому номеру.
  • Поддерживайте актуальность дат поверки, типов датчиков, шкал, позиций и других характеристик.
  • Перед обновлением приложения или массовым изменением данных сделайте резервную копию базы данных.
  • Если операция выполнена не так, как ожидалось, не повторяйте массовое действие вслепую — сначала проверьте состояние приборов и историю перемещений.

Инструкция описывает основные действия в текущем интерфейсе. Набор доступных операций зависит от прав пользователя и версии приложения.

Управление пользователями

Создавать пользователей и назначать им права может только администратор. Новые учётные записи получают права обычного пользователя.
