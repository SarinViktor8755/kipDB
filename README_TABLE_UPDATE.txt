Обновление таблицы приборов

Что изменено:
- Главная таблица приборов приведена к структуре приложенного примера.
- Колонка «Шкала» удалена.
- Остались 18 колонок: Заводской номер, Позиция, Тип датчика, ЕИ,
  Минимум шкалы, Максимум шкалы, П/К, Дата поверки, МПИ,
  Дата следующей поверки, Класс точности, Красная черта, Списание,
  Отложенная поверка, Движение, Строка, Группа, Наименование позиции.
- Для широкого перечня добавлена горизонтальная прокрутка.
- Поля, которых не было в прежней схеме SQLite, хранятся в details_json;
  при запуске существующая БД автоматически получает недостающую колонку.
- Приложенная таблица преобразована в devices-test-data.json (3000 записей).
  Данные автоматически импортируются только если таблица devices пуста.

Безопасность данных:
- Существующие записи не удаляются и не перезаписываются.
- Если в текущей БД уже есть приборы, автоматический импорт тестовых записей не выполняется.
- Перед заменой проекта рекомендуется сделать резервную копию kip.db.

Сборка: mvn package
Запуск: штатным способом проекта.


Дополнительное исправление интерфейса (v2):
- Таблица «Все приборы» имеет фиксированную минимальную ширину и собственную горизонтальную полосу прокрутки; в HTML и JS сверено соответствие 18 заголовков и 18 ячеек строки.
- Окно «Редактировать прибор» расширено и разделено на блоки: идентификация, метрологические характеристики, поверка и состояние, учётные сведения, фотография.
- В форму добавлены все 18 полей перечня (без отдельной колонки «Шкала»); дополнительные поля отправляются в API и сохраняются в details_json.
- При удалении фотографии отправляются также все заполненные дополнительные поля, чтобы не потерять их при обновлении записи.
- Проверка JavaScript: node --check выполнена успешно. Полная сборка Java не запускалась (Maven в среде отсутствует).
