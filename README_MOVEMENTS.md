# kipBD — окно «Перемещения»

## Что добавлено
- Отдельная вкладка «Перемещения» в главной навигации.
- При открытии загружаются последние 150 записей.
- Поиск выполняется на сервере по названию прибора, заводскому номеру, ID, типу операции, местам, примечанию и ответственному.
- Кнопка «Загрузить все» загружает полный журнал; появляется кнопка возврата к последним 150.
- Записи сгруппированы по дате операции, новые даты показываются первыми.
- В строке отображаются дата/время, прибор, заводской номер, операция, откуда, куда, примечание и пользователь.
- Нажатие на название прибора открывает карточку прибора, если он уже присутствует в текущем списке приборов.
- Для выборки добавлен индекс SQLite по дате/времени перемещения.

## API
GET /api/movements?q=...
Возвращает последние 150 совпадений.
GET /api/movements?all=true&q=...
Возвращает все совпадения.

## Сборка
Требуется Java 17 и Maven:
mvn clean package -Pprod

Исполняемый JAR появится в target/kip.jar.
